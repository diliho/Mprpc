**基于 Muduo+Protobuf 的简易 RPC 通信框架（个人学习实践项目）**

- 基于 Protobuf 定义 RPC 服务接口与通信协议，结合 Muduo Reactor 多线程网络库实现服务端请求分发与客户端异步调用，自定义 4 字节长度头 + Proto 消息的二进制通信协议；
- 封装 ZooKeeper C API 实现服务注册与发现，利用临时节点 + Watcher 回调感知服务上下线，实现客户端本地缓存加速服务发现与降级；
- 封装 hiredis 实现通用 Redis 客户端，使用 mutex 保证线程安全，支持断线自动重连；
- 基于 Redis + Lua 脚本实现分布式令牌桶与滑动窗口限流算法，支持按服务/方法/来源 IP 多级粒度控制请求量；
- 通过 Redis INCR/ZSet 按分钟聚合 RPC 调用量、错误率与 P99 延迟采样，搭建基础监控数据采集层；
- 实现客户端三态熔断器与有限重试机制，覆盖网络超时、序列化失败、服务不可达等异常场景；
- 实现线程安全异步日志引擎（生产者-消费者模型，mutex + condition_variable），设计三级结构化错误码体系（框架/系统/业务）；
- 基于 C++11 标准开发（智能指针、lambda、atomic、chrono、thread），CMake 构建产出静态库供多节点部署；
