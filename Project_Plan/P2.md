## 2. Python SDK 完成情况

### 2.1 C++ 绑定层（pybind11）

**文件**：`python_sdk/bindings/mprpc_module.cc`

已绑定的 C++ 核心能力：
- `init(config_file)` — 从配置文件初始化 Mprpc 框架（内部调用 `MprpcApplication::Init`）
- `get_config()` — 获取当前配置字典
- `RpcConfig` — 配置读写（load/get/set/[]）
- `RpcController` — RPC 控制器（failed/error_text/set_failed）
- `ZKClient` — ZooKeeper 客户端（start/get_data/is_connected）

**技术难点解决**：
- pybind11 trampoline 类无法继承 protobuf `RpcChannel`（多继承类型注册问题）
- `char**` 参数（`MprpcApplication::Init(argc, argv)`）不兼容 pybind11 类型系统 → 改为 `init(config_file)` 接口
- libmprpc.a 需要 `-fPIC` 编译才能链接到 .so → 在根 CMakeLists.txt 添加 `CMAKE_POSITION_INDEPENDENT_CODE ON`

### 2.2 纯 Python RPC 通道

**文件**：`python_sdk/mprpc/channel.py`

实现了完整的 Mprpc 线协议（Wire Protocol）：

```
请求格式：[4字节header_size(LE)] [RpcHeader protobuf] [args protobuf]
响应格式：[4字节header_size(LE)] [RpcHeader protobuf] [args protobuf]
```

RpcHeader protobuf 手动编解码（无需 .proto 编译）：
- 字段：service_name, method_name, args_size, version, trace_id
- Varint 编码完全匹配 protobuf 规范

**核心 API**：
```python
from mprpc import init, RpcChannel
init("test.conf")
channel = RpcChannel()
response = channel.call("UserService", "Login", request_bytes)
```

特性：
- 通过 ZKClient 服务发现
- 超时控制（connect_timeout / recv_timeout）
- 自动重试（默认3次）
- TraceID 自动生成
- 支持 Unicode 服务名

### 2.3 异步 RPC 通道

**文件**：`python_sdk/mprpc/async_channel.py`

基于 `asyncio` 的非阻塞 RPC 调用：
```python
channel = AsyncRpcChannel()
response = await channel.call("UserService", "Login", request_bytes)
```

### 2.4 指标收集器

**文件**：`python_sdk/mprpc/metrics.py`

Python 侧 RPC 指标收集：
- 调用计数、错误计数、延迟统计（avg/max/min）
- 限流拦截计数
- Prometheus 文本格式导出
- 完全对齐 C++ `MetricsCollector` 能力

## 4. 遇到的技术问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| libmprpc.a 链接 .so 失败 | 静态库未用 -fPIC 编译 | 根 CMakeLists.txt 添加 `CMAKE_POSITION_INDEPENDENT_CODE ON` |
| pybind11 trampoline 类继承 protobuf RpcChannel | 多继承类型注册冲突 | 改用简化包装类，不继承 protobuf 基类 |
| `py::init<>()` 报 type_not_registered | PyRpcProvider 缺少完整定义 | 去掉 Python 侧 Provider 的 start() 方法 |
| `char**` 参数不兼容 pybind11 | Python 无法传递 C 字符串数组 | 改为 `init(config_file)` 接口 |
| `__init__.py` import 失败 | .so 在 build/ 目录不在 mprpc/ | 编译后 copy .so 到 mprpc/ 目录 |
| FastAPI 0.139 路由列表不显示子路由 | _IncludedRouter 嵌套结构 | 实际路由已注册，通过 TestClient 验证可用 |
| pybind11 -Wunused-variable 警告 | 宏展开产生的未使用变量 | 添加 `[[maybe_unused]]` 属性 |
