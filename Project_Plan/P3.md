## 1. 阶段三交付物

### 1.1 管控面 Phase 3 API（新增 3 个 Router，约 20+ 端点）

#### 监控 API `/api/v1/monitor`
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/summary` | 聚合指标（QPS/延迟/错误率） |
| GET | `/trend` | 时间序列趋势（从 Prometheus 查询） |
| GET | `/node/{ip}` | 单节点指标详情 |
| GET | `/grafana/embed` | Grafana 嵌入 URL |
| GET | `/prometheus/status` | Prometheus 连接状态 |

#### 链路追踪 API `/api/v1/trace`
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/{trace_id}` | 按 TraceID 查询调用链 |
| GET | `` | 最近追踪记录列表 |
| DELETE | `` | 清除内存 trace 缓存 |

轻量方案：Provider/Consumer 输出结构化日志 `[TRACE] trace_id=xxx phase=connect/send/recv`，管控面解析聚合。

#### 告警 API `/api/v1/alerts`
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/active` | 当前活跃告警（从 AlertManager 查询） |
| GET/POST | `/rules` | 告警规则 CRUD |
| PUT/DELETE | `/rules/{id}` | 更新/删除规则 |
| GET | `/manager/status` | AlertManager 连接状态 |

默认规则：HighErrorRate、HighLatencyP99、QPSSuddenDrop、NodeDown

### 1.2 Vue3 前端（6 个完整页面）

**技术栈**：Vue 3 + TypeScript + Vite + Element Plus + ECharts + Pinia + Axios

| 页面 | 路径 | 核心功能 |
|------|------|----------|
| 集群总览 | `/` | 4 个统计卡片 + QPS/延迟/错误率折线图 + 节点列表 |
| 服务管理 | `/services` | 服务 CRUD + 实例列表 Drawer |
| 流量治理 | `/governance` | 限流规则表格 + 熔断规则表格 + 新增对话框 |
| 监控大盘 | `/monitor` | 3 个指标卡片 + 3 个 ECharts 趋势图 + Grafana iframe |
| 链路查询 | `/trace` | TraceID 搜索 + 瀑布图 + 最近追踪列表 |
| 运维中心 | `/ops` | 节点管理 + 配置下发 + 审计日志 + 告警规则 |

构建产物：`web/dist/`（生产就绪）

### 1.3 配置化改造

`control_plane/app/config.py` 支持环境变量配置：
- `MPRPC_DB_URL`：数据库连接（SQLite / MySQL）
- `MPRPC_PROMETHEUS_URL`：Prometheus 地址
- `MPRPC_GRAFANA_URL`：Grafana 地址
- `MPRPC_ALERTMANAGER_URL`：AlertManager 地址

## 2. 待手动安装的组件

以下组件需要 sudo 权限或 Docker，需手动安装：

```bash
# MySQL
sudo apt install mysql-server
sudo mysql -e "CREATE DATABASE mprpc_ee; CREATE USER 'mprpc'@'localhost' IDENTIFIED BY 'mprpc123'; GRANT ALL ON mprpc_ee.* TO 'mprpc'@'localhost';"
export MPRPC_DB_URL="mysql+pymysql://mprpc:mprpc123@localhost/mprpc_ee"

# Prometheus
sudo apt install prometheus
# 或 Docker: docker run -d -p 9090:9090 prom/prometheus

# Grafana
sudo apt install grafana
# 或 Docker: docker run -d -p 3000:3000 grafana/grafana

# AlertManager
# 配置 /etc/prometheus/alertmanager.yml
# 在 prometheus.yml 中配置 rule_files 和 alerting
```
